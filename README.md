# vNetMap - Issue Tracker

Welcome to the official issue tracker for [vNetMap](https://vnetmap.com).

This repository is used exclusively for tracking bugs, reporting issues, and collecting feature requests for the vNetMap ecosystem.

## ⚠️ Important Note
The core vNetMap backend and frontend are currently closed-source. However, to guarantee absolute transparency and verify our zero-knowledge architecture, we plan to open-source the Python Discovery Agent in the near future. This will allow you to audit exactly what data is collected and how the end-to-end encryption is handled locally before any metadata leaves your network.

## 🐛 How to report a bug or request a feature
Please use the provided Issue Templates. Click on the "New Issue" button and select either "Bug report" or "Feature request". The forms will guide you through all necessary details.

Before opening a new issue, please search the existing issues to avoid duplicates.

## 🛡️ Security Vulnerabilities
If you discover a security vulnerability, please do **NOT** open a public issue. Instead, send an email directly to [support@vnetmap.com](mailto:support@vnetmap.com?subject=Report%20Security%20Vulnerabilities). We take security very seriously and will respond immediately.
